# 안녕하세요!

컴퓨터공학을 전공하며 다양한 기술과 프로젝트를 경험하고 있는 이상현입니다.

프로그래밍을 통해 아이디어를 실제로 구현하는 과정에 흥미를 느끼며, 새로운 기술을 배우고 이를 프로젝트에 적용하는 것을 좋아합니다.

## 관심 분야

### 웹 및 모바일 애플리케이션 개발

사용자가 실제로 활용할 수 있는 서비스를 만드는 데 관심이 있습니다. 웹과 모바일 환경에서 사용자 경험과 기능 구현을 함께 고민하고 있습니다.

특히 단순히 기능을 구현하는 데 그치지 않고, 사용자가 편리하게 이용할 수 있는 서비스를 개발하는 데 관심이 있습니다.

## 프로젝트 경험

### 1. 감사 나눔 웹사이트

일상에서 느낀 감사한 마음을 다른 사람들과 나눌 수 있도록 제작한 웹사이트입니다.

그룹을 생성하고 참여하여 감사의 내용을 공유할 수 있는 서비스를 구현했습니다. 개발 과정에서 데이터베이스와 사용자 권한 관리, 실시간 데이터 반영 등을 경험했습니다.

이를 통해 실제 사용자를 고려한 서비스 설계와 기능 구현의 중요성을 배웠습니다.

### 2. SetLog 스타일 Android 애플리케이션

일상의 순간을 기록하고 친구들과 공유하는 SetLog 서비스를 참고하여 제작한 Android 애플리케이션입니다.

Kotlin과 Android Studio를 사용하여 개발했으며, Firebase Authentication을 통한 로그인 및 회원가입, 친구 추가, 일상 기록 작성, 친구들의 기록 확인 등의 기능을 구현했습니다.

이 프로젝트를 통해 모바일 애플리케이션의 화면 구성과 사용자 인증, 데이터베이스 연동 및 데이터 공유 과정을 경험했습니다.

## 기술 및 도구

- **언어:** Python, Java, Kotlin, JavaScript, C, SQL
- **웹 개발:** React, Node.js, Express
- **모바일 개발:** Android Studio, Firebase
- **개발 도구:** Git, GitHub, VS Code, MySQL

## 학습 목표

앞으로는 개별 기술을 익히는 데 그치지 않고, 기획부터 구현, 테스트, 배포까지 하나의 프로젝트를 완성하는 역량을 키우고 싶습니다.

특히 사용자 관점에서 필요한 기능을 설계하고, 문제 발생 시 원인을 분석하여 개선하는 개발자가 되는 것이 목표입니다.
