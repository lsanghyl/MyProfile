## 프로젝트 소개

일상의 순간을 기록하고 친구들과 공유하는 SetLog 서비스를 참고하여 제작한 Android 애플리케이션입니다.

사용자가 자신의 일상을 기록하고, 친구들의 기록을 확인하며 서로의 일상을 공유할 수 있도록 구현했습니다.

## 개발 목적

Android 애플리케이션 개발 과정을 경험하고, 사용자 인증과 데이터베이스를 연동한 서비스를 직접 구현하는 것을 목표로 했습니다.

특히 단순한 화면 구성에 그치지 않고, 여러 사용자 간 데이터를 공유하는 기능을 구현하는 데 중점을 두었습니다.

## 개발 환경 및 사용 기술

- **개발 언어:** Kotlin
- **개발 도구:** Android Studio
- **사용자 인증:** Firebase Authentication
- **데이터베이스:** Firebase Realtime Database
- **개발 플랫폼:** Android

## 주요 기능

### 1. 로그인 및 회원가입

Firebase Authentication을 활용하여 이메일 기반 로그인 및 회원가입 기능을 구현했습니다.

### 2. 친구 추가 및 친구 목록

사용자를 검색하고 친구를 추가할 수 있도록 구현했습니다.

친구 관계가 양쪽 사용자에게 반영되도록 데이터베이스 구조를 구성했습니다.

### 3. 일상 기록 작성

사용자가 자신의 일상을 작성하고 저장할 수 있도록 구현했습니다.

### 4. 오늘의 기록 확인

작성한 기록을 별도의 화면에서 확인할 수 있도록 구성했습니다.

### 5. 친구들의 순간 보기

친구들이 공유한 기록을 확인할 수 있는 피드 화면을 구현했습니다.

### 6. 프로필 및 로그아웃

사용자 프로필을 확인하고 로그아웃할 수 있는 기능을 구현했습니다.

## 개발 과정에서 경험한 문제

### Firebase 데이터베이스 연동

친구를 추가했을 때 상대방의 친구 목록에도 관계가 반영되도록 구현하는 과정에서 데이터 구조를 고민했습니다.

이를 해결하면서 여러 사용자 간 데이터 관계를 관리하는 방법을 경험했습니다.

### 화면 전환 및 데이터 처리

기록을 확인하는 화면에서 오류가 발생하는 문제가 있었습니다.

화면 전환과 데이터 처리 과정을 점검하며 오류를 수정했습니다.

### 이미지 공유 기능

초기에는 사진 공유 기능도 고려했지만, Firebase Storage 사용에 따른 비용 문제를 고려하여 텍스트 중심의 공유 방식으로 조정했습니다.

## 프로젝트를 통해 배운 점

Android 애플리케이션의 화면 구성과 Activity 간 이동, Firebase를 이용한 사용자 인증 및 데이터베이스 연동을 경험했습니다.

특히 여러 사용자가 데이터를 공유하는 서비스를 구현하면서 데이터 구조와 사용자별 접근 방식의 중요성을 이해할 수 있었습니다.

앞으로는 사용자 경험을 개선하고, 더욱 안정적인 데이터 관리 기능을 갖춘 모바일 애플리케이션을 개발하고 싶습니다.
